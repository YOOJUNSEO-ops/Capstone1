# 우이신설선 접근성 분석 대시보드

보고서의 순서에 맞춘 접근성 분석 지도·그래프입니다. 생활인구 비교와 정릉 잔존 인구 6위 답사지의 현장사진을 포함합니다.

GitHub Pages에서 이 저장소의 `main` 브랜치 루트를 게시하면 `index.html`이 시작 화면이 됩니다.
분석 자료는 HTML에 내장되어 있으며, 배경지도와 외부 지도 링크는 인터넷 연결이 필요합니다.

자료: SGIS 거주인구, 서울시 생활인구, 서울시 역사마스터, © OpenStreetMap contributors.
수치는 고정 보행망 시나리오에 따른 추정치이며 실제 이용객 수나 개통의 인과효과가 아닙니다.
